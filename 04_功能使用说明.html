个人重要信息库

详细功能使用说明

版本: 1.0 | 日期: 2026年5月27日 | 用户手册

1. 快速开始

1.1 打开应用

直接在浏览器中打开 passwords.html 文件即可使用。无需安装任何软件或插件。

✓ 提示：应用完全在本地运行，所有数据存储在您的浏览器中，不会上传到任何服务器。

1.2 界面概览

应用界面分为以下几个部分：

  • 顶部：应用标题和存储路径提示
  • 工具栏：搜索、过滤、添加、导出、导入功能
  • 统计面板：显示记录总数和时间段统计
  • 批量操作栏：全选、批量导出、批量删除
  • 表单区域：添加或编辑记录的表单
  • 列表区域：显示所有保存的记录
  • 书签工具：快速收藏工具教程

2. 核心功能详解

2.1 添加新记录

步骤 1：点击工具栏中的 + 添加 按钮
步骤 2：表单会展开，显示以下字段：
  • 网站名称：例如 "GitHub"、"Gmail" 等
  • 网站地址：例如 "https://github.com"
  • 账号：用户名或邮箱
  • 密码：登录密码
  • 备注：可选的额外信息
步骤 3：填写至少一个字段（名称或地址）
步骤 4：点击 保存 按钮
✓ 成功：记录被添加到列表顶部，显示创建时间，并显示"已添加"提示。
💡 提示：
  • 名称和地址至少填写一个，其他字段可选
  • 创建时间会自动记录，便于后续统计和分组
  • 可以随时编辑记录，修改任何字段

2.2 查看和编辑记录

查看记录

所有保存的记录都显示在列表中，每条记录包含：

  • 网站名称（加粗显示）
  • 网站地址（可点击打开）
  • 账号和密码（密码默认隐藏）
  • 备注信息
  • 创建时间

编辑记录

步骤 1：找到要编辑的记录
步骤 2：点击记录右侧的 编辑 按钮
步骤 3：表单会展开并填充该记录的信息
步骤 4：修改需要更改的字段
步骤 5：点击 保存 按钮
✓ 成功：记录被更新，显示"已更新"提示。创建时间保持不变。
💡 提示：点击 取消 按钮可以放弃编辑。

2.3 密码管理

隐藏密码

为了安全起见，密码默认显示为点号（••••••）。

显示密码

步骤 1：找到包含密码的记录
步骤 2：点击记录右侧的 👁 按钮
✓ 成功：密码以明文显示。再次点击可以隐藏。

复制密码

步骤 1：点击 复制密码 按钮
✓ 成功：密码被复制到剪贴板，显示"已复制到剪贴板"提示。
⚠ 警告：
  • 不要在公共计算机上使用此应用
  • 不要将密码分享给他人
  • 定期更改重要账号的密码

2.4 删除记录

步骤 1：找到要删除的记录
步骤 2：点击记录右侧的 删除 按钮
步骤 3：在确认对话框中点击"确定"
✓ 成功：记录被删除，显示"已删除"提示。
⚠ 警告：删除操作无法撤销。如果误删，可以通过导入备份来恢复。

2.5 搜索功能

快速搜索

步骤 1：在工具栏的搜索框中输入关键词
步骤 2：列表会实时过滤，只显示匹配的记录

搜索会在以下字段中查找：

  • 网站名称
  • 网站地址
  • 备注
💡 提示：搜索不区分大小写，支持部分匹配。例如搜索"git"会匹配"GitHub"。

清除搜索

清空搜索框即可显示所有记录。

2.6 时间过滤

使用工具栏中的下拉菜单按时间范围过滤记录：

选项 说明
全部 显示所有记录
今天 显示今天添加的记录
本周 显示过去7天添加的记录
本月 显示本月添加的记录
💡 提示：搜索和时间过滤可以组合使用，例如搜索"GitHub"并选择"本周"，会显示本周添加的名称包含"GitHub"的记录。

2.7 批量操作

全选记录

步骤 1：在批量操作栏中勾选"全选"复选框
步骤 2：所有可见的记录都会被选中

单条选择

步骤 1：点击某条记录前的复选框
步骤 2：该记录被选中，选中数量会更新

批量导出

步骤 1：选择要导出的记录
步骤 2：点击 导出选中 按钮
步骤 3：下载 JSON 文件

批量删除

步骤 1：选择要删除的记录
步骤 2：点击 删除选中 按钮
步骤 3：在确认对话框中点击"确定"
✓ 成功：选中的记录被删除，显示"批量删除完成"提示。

3. 高级功能

3.1 数据备份与恢复

导出备份

定期导出备份可以防止数据丢失。

步骤 1：点击工具栏中的 导出备份 按钮
步骤 2：浏览器会下载一个 JSON 文件，文件名包含导出日期
✓ 成功：备份文件已下载，显示"备份已导出"提示。

导入数据

如果浏览器数据被清除或需要在其他设备上恢复数据，可以导入备份文件。

步骤 1：点击工具栏中的 导入 按钮
步骤 2：选择之前导出的 JSON 文件
步骤 3：数据会被导入，显示导入的记录数
✓ 成功：数据已导入，显示"已导入 X 条新记录"提示。
💡 提示：
  • 导入时会自动去重，相同 ID 的记录不会重复导入
  • 建议每周导出一次备份
  • 将备份文件保存在安全的地方，例如云盘或移动设备
⚠ 警告：备份文件包含所有账号和密码信息，请妥善保管，不要分享给他人。

3.2 快速收藏工具（书签工具）

快速收藏工具允许您从任意网页快速保存网站信息到信息库。

设置书签工具

步骤 1：按 Ctrl+Shift+B（Chrome/Edge）或 Cmd+Shift+B（Mac）显示浏览器书签栏
步骤 2：在本应用的"快速收藏工具"部分找到橙色的"📌 收藏到信息库"按钮
步骤 3：用鼠标按住该按钮，拖到浏览器书签栏上松开
✓ 成功：书签已添加到书签栏。

使用书签工具

步骤 1：浏览任意网页
步骤 2：点击书签栏中的"📌 收藏到信息库"书签
步骤 3：本应用会打开，网页标题和地址已自动填入表单
步骤 4：填写账号和密码
步骤 5：点击"保存"按钮
✓ 成功：网站信息已保存到信息库。
💡 提示：整个过程只需 3 秒，非常快速方便。

示例

假设您正在浏览 GitHub 网站：

  • 点击书签后，应用打开
  • 网站名称自动填入："GitHub: Let's build from here"
  • 网站地址自动填入："https://github.com"
  • 您只需填写账号和密码，然后保存

4. 数据存储与安全

4.1 数据存储位置

所有数据存储在浏览器的 localStorage 中，具体位置取决于您使用的浏览器：

浏览器 存储路径
Chrome %LOCALAPPDATA%\Google\Chrome\User Data\Default\Local Storage\leveldb\
Edge %LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Local Storage\leveldb\
Firefox %APPDATA%\Mozilla\Firefox\Profiles\<profile>\webappsstore.sqlite
⚠ 重要：请勿清除浏览器数据或删除上述目录，否则所有信息将丢失。

4.2 安全建议

  • 定期备份：每周导出一次备份，保存在安全的地方
  • 不在公共计算机上使用：避免在网吧、图书馆等公共场所使用此应用
  • 保护浏览器安全：定期更新浏览器和操作系统
  • 强密码：为重要账号设置强密码，定期更改
  • 备份文件安全：将导出的备份文件保存在加密的云盘或移动设备中

4.3 隐私保护

本应用完全在本地运行，所有数据都存储在您的浏览器中：

  • ✓ 数据不上传到任何服务器
  • ✓ 不收集任何个人信息
  • ✓ 不使用任何第三方服务
  • ✓ 完全离线运行

5. 常见问题

Q1: 如果我清除了浏览器数据怎么办？

A: 如果您之前导出过备份，可以通过"导入"功能恢复数据。如果没有备份，数据将无法恢复。这就是为什么建议定期导出备份。

Q2: 我可以在多个浏览器中使用吗？

A: 可以。每个浏览器都有独立的 localStorage，所以您需要在每个浏览器中分别导入数据。

Q3: 我可以在多个设备上使用吗？

A: 可以。您可以在每个设备上打开 HTML 文件，然后导入备份文件来同步数据。

Q4: 密码是否加密存储？

A: 不是。密码以明文形式存储在 localStorage 中。这就是为什么建议不要在公共计算机上使用此应用。

Q5: 我可以导出为其他格式吗？

A: 目前只支持 JSON 格式。您可以使用其他工具将 JSON 转换为 CSV 或 Excel 格式。

Q6: 应用支持哪些浏览器？

A: 支持所有现代浏览器，包括 Chrome、Edge、Firefox、Safari 等。不支持 Internet Explorer。

Q7: 我可以修改 HTML 文件吗？

A: 可以，但不建议。修改可能会导致应用无法正常工作。如果您想自定义功能，建议联系开发者。

Q8: 应用会自动保存吗？

A: 是的。每次您添加、编辑或删除记录时，应用都会自动保存到 localStorage。
