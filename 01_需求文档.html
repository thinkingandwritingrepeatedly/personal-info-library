个人重要信息库

需求文档

版本: 1.0 | 日期: 2026年5月27日 | 状态: 已完成

1. 项目概述

个人重要信息库是一个本地化的个人信息管理工具，用于安全地存储和管理个人重要信息，如网站地址、账号、密码等。该应用采用单文件HTML设计，数据存储在浏览器本地，确保隐私性和安全性。

2. 项目目标

  • 提供一个简洁易用的个人信息管理界面
  • 确保数据完全本地存储，不上传到任何服务器
  • 支持数据的导入导出，便于备份和迁移
  • 提供快速收藏工具，支持从任意网页快速保存信息
  • 提供统计分析功能，帮助用户了解信息库的使用情况

3. 功能需求

3.1 核心功能

需求 FR-001: 信息录入
优先级: 高
用户可以添加新的信息记录，包括：
  • 网站名称（必填或地址必填）
  • 网站地址（必填或名称必填）
  • 账号（可选）
  • 密码（可选）
  • 备注（可选）
  • 创建时间（自动生成）
需求 FR-002: 信息查看与编辑
优先级: 高
  • 用户可以查看所有已保存的信息
  • 用户可以编辑已有的信息记录
  • 密码默认隐藏，显示为点号（••••••）
  • 用户可以点击眼睛图标切换密码显示/隐藏
需求 FR-003: 信息删除
优先级: 高
  • 用户可以删除单条信息记录
  • 删除前需要确认
  • 支持批量删除选中的记录
需求 FR-004: 搜索与过滤
优先级: 高
  • 支持按名称、地址、备注进行搜索
  • 支持按时间分组：全部、今天、本周、本月
  • 搜索和过滤可以组合使用
需求 FR-005: 数据持久化
优先级: 高
  • 所有数据存储在浏览器 localStorage 中
  • 数据在浏览器关闭后仍然保留
  • 提供存储路径提示，警告用户不要清除浏览器数据

3.2 高级功能

需求 FR-006: 数据导出备份
优先级: 高
  • 用户可以导出全部数据为 JSON 文件
  • 用户可以导出选中的数据为 JSON 文件
  • 导出文件名包含导出日期
需求 FR-007: 数据导入恢复
优先级: 高
  • 用户可以导入之前导出的 JSON 文件
  • 导入时自动去重（相同 ID 的记录不重复导入）
  • 导入成功后显示导入的记录数
需求 FR-008: 批量操作
优先级: 中
  • 支持全选/反选所有可见记录
  • 显示已选择的记录数
  • 支持批量导出选中记录
  • 支持批量删除选中记录
需求 FR-009: 快速收藏工具（书签工具）
优先级: 中
  • 生成可拖动的书签工具
  • 用户可以将其拖到浏览器书签栏
  • 点击书签时自动打开本应用，并填入当前网页的标题和地址
  • 用户只需填写账号和密码即可保存
需求 FR-010: 统计分析
优先级: 中
  • 显示总记录数
  • 显示今日新增记录数
  • 显示本周新增记录数
  • 显示本月新增记录数
  • 显示出现频率最高的前3个关键字及其出现次数

3.3 用户界面需求

需求 UI-001: 响应式设计
优先级: 中
  • 支持桌面端（1024px 以上）
  • 支持平板端（600px - 1024px）
  • 支持手机端（600px 以下）
需求 UI-002: 深色主题
优先级: 低
  • 采用深色主题设计，保护用户视力
  • 使用渐变色和高对比度提升视觉效果
需求 UI-003: 用户反馈
优先级: 中
  • 操作成功时显示 Toast 提示
  • 操作失败时显示错误提示
  • 提示自动消失

4. 非功能需求

需求类别 具体要求
安全性 数据完全本地存储，不涉及网络传输；密码默认隐藏显示
性能 页面加载时间 < 1 秒；操作响应时间 < 200ms
可用性 界面直观易用，无需用户手册即可上手
兼容性 支持 Chrome、Edge、Firefox 等现代浏览器
可维护性 单文件设计，易于部署和维护

5. 数据结构

5.1 信息记录结构

{
  id: string,              // 唯一标识符（时间戳）
  name: string,            // 网站名称
  url: string,             // 网站地址
  user: string,            // 账号
  pass: string,            // 密码
  note: string,            // 备注
  createdAt: ISO8601       // 创建时间
}

6. 使用场景

场景 1: 保存新网站信息

  1. 用户点击"+ 添加"按钮
  2. 填写网站名称、地址、账号、密码等信息
  3. 点击"保存"按钮
  4. 信息被添加到列表中，显示创建时间

场景 2: 快速收藏网站

  1. 用户将"收藏到信息库"书签拖到浏览器书签栏
  2. 浏览网页时，点击书签
  3. 自动打开信息库，网页标题和地址已自动填入
  4. 用户填写账号密码后保存

场景 3: 查找信息

  1. 用户在搜索框输入关键词
  2. 列表自动过滤显示匹配的记录
  3. 用户可以选择时间范围进一步过滤

场景 4: 数据备份与恢复

  1. 用户定期点击"导出备份"下载数据
  2. 如果浏览器数据被清除，用户可以点击"导入"恢复数据

7. 验收标准

功能 验收标准
信息录入 能成功添加包含所有字段的记录，数据正确保存
信息查看 所有记录正确显示，密码默认隐藏
搜索过滤 搜索结果准确，时间过滤正确
数据持久化 关闭浏览器后数据仍然存在
导出导入 导出的数据能正确导入，无数据丢失
书签工具 能正确获取网页标题和地址，自动填入表单
统计分析 统计数据准确，关键字提取正确

8. 约束条件

  • 单文件 HTML 应用，无需后端服务
  • 数据存储在浏览器 localStorage，容量限制约 5-10MB
  • 不支持跨浏览器数据同步
  • 不支持多用户管理
  • 不支持数据加密存储（用户需自行保护浏览器安全）
